# Анализ инвестиционного поведения клиентов

## Описание проекта

Проект посвящен исследованию инвестиционного поведения клиентов инвестиционной платформы.
Цель работы — выявить факторы, влияющие на инвестиционную активность пользователей, а также сформулировать продуктовые гипотезы для повышения вовлеченности клиентов.

Исследование выполнено на основе датасета с данными о клиентах и их инвестиционной активности.

---

## Цели проекта

* Провести исследовательский анализ данных (EDA)
* Изучить связь между демографическими характеристиками и инвестиционной активностью
* Проанализировать влияние уровня дохода и образования
* Выполнить статистический анализ данных
* Сформулировать продуктовые гипотезы для развития инвестиционного продукта

---

## Данные

Датасет содержит более 458 000 записей с информацией о клиентах инвестиционной платформы:

* возраст клиентов
* уровень дохода
* образование
* семейное положение
* наличие детей
* инвестиционные обороты
* размер инвестиционного портфеля
* пользовательская активность

## Ключевые выводы

* Основная группа инвесторов находится в возрасте 33–47 лет
* Доход пользователей слабо коррелирует с инвестиционной активностью
* Уровень образования влияет на инвестиционное поведение клиентов
* Семейный статус может быть связан с размером инвестиционного портфеля
* Начинающим инвесторам требуется более простой вход в инвестиционные продукты

---

## Продуктовые гипотезы

### Автоподбор инвестиционного портфеля для новичков

Введение автоматического подбора инвестиционного портфеля для начинающих инвесторов может увеличить средний чек первой сделки и снизить барьер входа в инвестиции.

### Упрощение интерфейса

Упрощение пользовательского интерфейса для начинающих инвесторов может повысить вовлеченность клиентов со средним уровнем образования.

### Семейные инвестиционные планы

Создание семейных инвестиционных планов может увеличить средний размер инвестиционного портфеля клиентов, состоящих в браке.
